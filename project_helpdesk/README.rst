================
Project Helpdesk
================

Project Helpdesk core bundle

Configuration
=============

1. Install the module
2. Create an outgoing email server
3. Create incoming email server
    - Set a company to which the issues are created
    - Assign "Create a new record": "Project task"
    - (Assign "Related project")
4. Setup helpdesk project(s)
    - Go to project settings
    - Set "Sender email"
5. Setup helpdesk stages
    - Go to Projects->Configuration->Stages
    - Set one Helpdesk-project stage as "Closing stage"
    - Set one Helpdesk-project stage as "Re-open stage"
