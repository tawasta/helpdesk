==============================
Project task Mattermost hooks
==============================

Pushes task events to a Mattermost channel using incoming webhooks.


Installation
============

Install the module form Settings->Local Modules

Configuration
=============
Fill in the missing information under Settings > Technical > Mattermost hooks:
- company_id
- hook key
- option values (channel, username, icon_url)

Go to project you want to trigger hooks and select "use_mattermost_hooks"
